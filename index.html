Digital Asset Links test sign-in

A throwaway form whose only purpose is to get a password saved for this origin, so that an Android application can then be tested against the get_login_creds statement published at /.well-known/assetlinks.json.

Invent a username and password here. Nothing is transmitted anywhere and nothing is checked — the page is static and there is no server to receive it.

If the browser does not offer to save the password, press the button below. It calls the Credential Management API directly, which writes to the browser password store without depending on form-submission heuristics.

Why the second button matters. If the site itself cannot retrieve a credential for its own origin, then no credential is stored and an Android app failing to get one proves nothing about the asset-links association. This separates the two.
